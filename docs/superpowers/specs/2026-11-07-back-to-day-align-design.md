# 回到那天 · 对齐原版设计（2026-11-07 · 方案A）

## 意图与为什么
把 back-to-day 页的视觉与交互全面对齐原版《去留》。验收标准 = 用户拿原版同页对比无行为差异。

## 证据（用户实机观察 + 截图）
- IMG_1516/1493：墙页布局基准；IMG_1517：预览页基准
- 原版文案：「双指把照片缩小，可以回到那天」「回到那天为会员功能」（会员部分已裁剪不复刻）

## Goals
1. **照片墙错落**：两行横滚，每张**保留自身宽高比**（高 = 列宽 / aspect，限幅 0.8–2.2×列宽），实况照片左上"◉ 实况"徽章
2. **☰ 过滤**：弹出菜单 照片 / 视频 / 照片和视频（会话级状态，默认"照片和视频"）
3. **✓ 右上 = 返回**（进入前页面）
4. **↻ = 滚回锚点照片**（捏合进墙的那张）位置
5. **刻度条可拖动**：拖动即跳转墙的水平滚动位置；指示块随滚动实时反映进度
6. **点照片 → 预览页**（新路由 day-preview）：
   - 纯黑底；左上 省市区（小字）+ 日期（大字 2025/4/12 风格）
   - 照片保比例居中；实况徽章 + 长按播放一次（复用 LivePhotoView/getLiveSource）
   - 底部三圆钮：♡ 收藏 toggle（复用 setFavoriteSafe）· ⓘ 跳信息页 · ↑ 系统分享
   - **下滑返回**（用 modal 手势关闭实现，原生即支持）

## Non-goals
- 多选批量入队（T10 自创增强，**移除**；批量删除仍走回收站）
- 会员横幅、"播放展开"reveal 动效、飞向灵动岛

## Anti-goals
- 再次出现"自创交互语义"（如 ✓ 曾被我们做成全选）——一切以用户实机观察为准

## 约束
- Expo Go 可运行，只用已装依赖；不新建原生模块
- 复用现有：photo-info 路由、placeParts、formatTime、setFavoriteSafe、getLiveSource

## 方案对比（用户已选 A）
- **A 完全对齐原版**（选）：墙纯浏览 + 独立预览页；改动集中在 back-to-day.tsx 重写 + 新增 day-preview.tsx
- B 对齐 + 长按多选增强：原版无此交互，用户否
- C 预览做墙内叠加层：原版是独立页面，不符

## 留给实现者裁量
- 预览页退出用 modal swipeToDismiss（下滑手势原生自带），若 Expo Go 手势异常则退化为 PanResponder 下滑
- 过滤菜单复用 CategoryMenu 样式或简化 ActionSheet
- 刻度条用 PanResponder 映射 scrollX；无动画需求从简
