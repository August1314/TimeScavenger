## 2. 首页（IMG_1490 为准）
- **全屏渐变背景**：照片主色暖调 → 底部 `#161627`；无按钮居中版式。
- **中央卡组预览**（用户裁决 2026-11-06 19:02：三卡统一薄白边，**废弃拍立得卡纸**）：中卡=薄白边圆角照片卡（0.38W×0.62W，正立居前）；左右卡=同款白边卡，外翻 ±7°、上移探出、缩 0.92。

## 3. 浏览页（live_current.png 用户实机截图为准 · 2026-11-06 18:31 修正）
- **重要更正**：浏览页照片为**全出血圆角卡**（cover 裁剪），IMG_1492 中的拍立得只是那张照片本身是拍立得风格照片；拍立得样式仅用于首页中央卡组卡。
- 全出血卡：左右边距≈20pt（宽=屏宽-40pt），上缘 y≈130pt，下缘至底栏上方；radius 24pt；阴影 0/10/30 rgba(0,0,0,0.4)；**无后层卡边**（单卡）。
- **浏览页无底部 tab 栏**（原版为全屏流程）→ 复刻已将 review/photo-info/back-to-day/pending 提升为根 Stack 路由。
- 顶栏：左右圆钮 **56pt**（`capsuleLight` 毛玻璃底 + 白图标 chevron-back / share-outline）；**中央进度条=短横线**（实测宽 **110pt**、高 4pt、轨道 `rgba(255,255,255,0.25)`、填充白色，居中，非全宽）。
- 实况徽章：左上 `rgba(20,20,28,0.6)` 胶囊 "◉ 实况 ▾"。
- 底栏：左 ♡ 圆钮 **56pt** `capsuleDark` 实底+heart-outline；中时间胶囊 `#2B2B39` 圆角 26（第一行时间 16pt/600，第二行位置 13pt/`rgba(255,255,255,0.55)`，右侧 ⓘ 26pt 小圆钮）；右 ↩ 圆钮 56pt。
- 回收站（IMG_1498）：底部滑出 **modal 卡片**（圆角顶）、标题居中、右上 ✕ 圆钮、缩略图 **3 列**+绿色✓角标、底部"放弃，回到首页"(灰)+"确认删除"(红)。
- 上滑删除：卡片飞出+顶部红光渐亮（已有）；**删除后卡从下方补位带弹性**。
