## 2. 首页（IMG_1490 为准）
- **全屏渐变背景**：照片主色暖调 → 底部 `#161627`；无按钮居中版式。
- **中央卡组预览**：3 张卡。中间卡=拍立得式（白衬卡+彩色卡纸+照片内嵌，卡纸色随照片）；左右卡=白边圆角照片卡，外翻 ±8°、下移 14pt、缩 0.92。
- 左上分类胶囊（毛玻璃浅色）；右上垃圾桶+角标。
- 底部悬浮胶囊 tab：`#2A2A37` 92%，高 62pt，圆角 31，左右缩进 24；选中项图标+文字 `#4C8DFF`，未选 `rgba(255,255,255,0.55)`。
- **点中间卡进入浏览页**（原 app 首页即卡组，点卡开始回顾）。

## 3. 浏览页（IMG_1492/1497 为准）
- 照片**全出血圆角卡**：宽=屏宽-28pt，上缘 y≈130pt，下缘至底栏上方；radius 24pt；阴影 0/10/30 rgba(0,0,0,0.4)。
- 顶栏：返回圆钮 44pt（`capsuleLight` 底+白 ‹）；**中央进度条=短横线**（宽 60pt、高 3pt、轨道 `rgba(255,255,255,0.25)`、填充白色，非全宽）；分享圆钮。
- 实况徽章：左上 `rgba(20,20,28,0.6)` 胶囊 "◉ 实况 ▾"。
- 底栏（从下往上）：左 ♡ 圆钮 52pt；中时间胶囊 `#2B2B39` 圆角 24（第一行时间 16pt/600，第二行位置 13pt/`rgba(255,255,255,0.55)`，右侧 ⓘ 18pt）；右 ↩ 圆钮。
- 上滑删除：卡片飞出+顶部红光渐亮（已有）；**删除后卡从下方补位带弹性**。
